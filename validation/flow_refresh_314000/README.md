## بازتولید در پوشهٔ مرحله‌بندی

از Python 3.12 با JAX 0.11.1، NumPy 2.3.5، SciPy 1.17.0 و Matplotlib 3.10.8 استفاده شد.
به متغیرهای `SOAP`، `ARCHIVE` و `REWRITE` مسیر مخزن‌های خواندنی بدهید.
این مسیرها به‌ترتیب به نسخه‌های ثابت مدل، آزمایش و کد شتاب‌دهی اشاره می‌کنند.
`STAGE` باید مسیر جداگانه‌ای برای خروجی‌های تازه باشد.
دستورها از ریشهٔ پایان‌نامه اجرا می‌شوند.

```bash
export PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 JAX_ENABLE_X64=true
export MPLCONFIGDIR=/tmp/thesis-refresh-mpl

driver=figs/chapter4/refresh_flow_inputs.py
renderer=figs/chapter4/render_flow_refresh.py

python "$driver" --soap "$SOAP" --archive "$ARCHIVE" --output "$STAGE/forward/forward" forward

for case in corners_beta4 corners_beta5 oblique_beta5; do
  for kind in timed geometry; do
    python "$driver" --soap "$SOAP" --archive "$ARCHIVE" \
      --output "$STAGE/$kind/$case" "$kind" --case "$case"
  done
done

python "$driver" --soap "$SOAP" --archive "$ARCHIVE" --cache-source "$REWRITE" \
  --output "$STAGE/count/run" count --profiles \
  beta5 lobes4_r30 flat30 nine30 parabolic skew_b3 twin_b3_r30 mixed shoulder waves3_r30

for group in forward timed geometry count; do
  python "$renderer" --soap "$SOAP" --archive "$ARCHIVE" --staging "$STAGE" \
    --output "$STAGE/rendered/$group" "$group"
done
```

پوشه‌های خروجی باید تازه باشند.
دستور رسم شکل‌های اصلی پایان‌نامه را بازنویسی نمی‌کند.
فایل‌های JSON، مسیر شکل، هش ورودی و خروجی، و برچسب‌های مرتبط را ثبت می‌کنند.
