# اعتبارسنجی حرکت ذره با پاسخ‌های منتشرشده

این بایگانی داده‌ها و کد دو آزمون مرجع را نگه می‌دارد.
مسیرها با حل‌گرهای عصبیِ ویژهٔ هر آزمون محاسبه شدند.
گزارش کامل و نسخهٔ اصلی شکل‌ها در همین بایگانی موجودند. [گزارش پشتیبان](supporting_report.pdf) · [منبع و داده‌های اجرا](original/)

## بررسی داده‌های ذخیره‌شده

دستورها را از همین پوشه اجرا کنید.
اجرای بررسی با NumPy کافی است.
بازسازی شکل‌ها از داده‌ها به SciPy و Matplotlib نیاز دارد.

```sh
python -m pip install numpy scipy matplotlib
python verify_saved_metrics.py
```

بررسی، خطاهای ده حالت مغناطیسی و سه حالت کانال را دوباره محاسبه می‌کند.
این مرحله، تطابق رویدادهای جذب یا عبور را هم کنترل می‌کند.
جدول پایان‌نامه از چهار ردیف فایل خلاصه استفاده می‌کند. [خلاصهٔ عددی](approved_summary.csv) · [فرادادهٔ تأیید](verified_metrics_and_provenance.json)

## آزمون مغناطیسی

مرجع، معادلهٔ ۵۹ فرلانی و انگ است.
اجرای بایگانی‌شده روی CPU انجام شد و عدد آغازین مولد اعداد تصادفی ۴۲ بود.
پنج شعاع ۴۰۰ تا ۶۰۰ نانومتر و دو فاصله بررسی شدند.
فاصله‌ها نسبت به شعاع آهنربا ۲ و ۲٫۲۵ بودند.
هر حالت وزن‌های جداگانه داشت.
خطای مسیر بر شعاع کانال و اختلاف جذب بر شعاع آهنربا تقسیم شد.
معیار مسیر از نقاط مشترک معتبر با شرط |X_PINN| < 0.98 استفاده می‌کند.
بیشینهٔ اختلاف مکان جذب فقط در حالت‌های جذب مقایسه شد. [مقاله](https://doi.org/10.1103/PhysRevE.73.061919) · [تنظیمات اجرا](original/data/magnetic/training.json) · [خطاها](original/data/magnetic/validation.json)

## آزمون کانال موج‌دار

مدل مرتبهٔ اول مقاله، میدان حامل را تعیین کرد.
شکل ۶ مقاله، منحنی نیروی برآ را فراهم کرد.
مسیرها و پوش شکل ۹(a-2) مرجع ارزیابی بودند.
عدد رینولدز ۱۰، پارامتر فرکانس ۲ و پارامتر اندازهٔ ذره ۰٫۲ بود.
دامنه‌های دیواره ۰، ۰٫۰۵ و ۰٫۱۰ بودند.
خطاها برحسب نیم‌عرض متوسط کانال گزارش شدند.
در کانال صاف، بازهٔ محوری ۱۰ تا ۱۹۹۰ به‌کار رفت.
برای کانال موج‌دار، خطاهای دو کران یک‌جا محاسبه شدند.
نشانگر used_for_error نمونه‌های معتبر را مشخص می‌کند.
۲۰ واحد از هر انتهای بازهٔ موج‌دار کنار گذاشته شد.
سه دوره در محل اتصال مسیر PDF فقط برای نمایش درون‌یابی شدند.
اختلاف حل مستقل، مقایسهٔ دو حل همان معادله است. [مقاله](https://doi.org/10.1017/jfm.2023.558) · [یادداشت بازتولید](original/data/wavy/reproduction_notes.md) · [معیارها](original/data/wavy/metrics.json)

## بازتولید شکل‌ها و اجراهای جدید

برای حفظ فایل‌های بایگانی، کپی موقت را برای رسم به کار ببرید.

```sh
bench_tmp=$(mktemp -d)
cp -a original/. "$bench_tmp/"
cd "$bench_tmp"
python make_figures.py --magnetic data/magnetic --wavy data/wavy
```

اجرای مغناطیسی جدید به PyTorch نیاز دارد و وزن‌های خودش را می‌سازد.
بستهٔ حاضر مسیرها، تنظیمات و معیارهای اجرای گزارش‌شده را دارد.
برای اجرای کانال موج‌دار، راهنمای بازتولید و PDF رسمی مقاله لازم‌اند.
خروجی اجرای جدید را در پوشهٔ جداگانه ذخیره کنید. [کد مغناطیسی](original/rerun_magnetic.py) · [راهنمای کانال موج‌دار](original/data/wavy/reproduction_notes.md)
