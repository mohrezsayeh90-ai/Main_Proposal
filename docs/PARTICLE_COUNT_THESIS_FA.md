## کنترل داده و تفسیر

هر پنجاه خانهٔ `summary.csv` با `summary.json` تطبیق داده شد.
ترتیب ده پروفایل با زبری ثبت‌شده سازگار بود.
پنجاه نرم نسبی روی شبکهٔ مشترک ۴۰۹۷نقطه‌ای بازحساب شدند.
ستون‌های `truth` و `estimated` با سرعت مرجع مشترک استفاده شدند.
ستون `estimated_own_mean` در این شکل‌ها استفاده نشد.
معیار درصدی برابر `100*norm(estimated-truth)/norm(truth)` است.
پروفایل‌ها بدون هموارسازی اضافی رسم شدند.

| تعداد ذرات | میانهٔ خطای نسبی ورودی، درصد |
| --- | --- |
| ۲ | ۲۱٫۹۸۶۹۶۲۵۲۴۲ |
| ۳ | ۱۰٫۲۷۲۶۴۶۴۹۹۰ |
| ۴ | ۸٫۲۹۲۸۹۷۵۰۳۴ |
| ۵ | ۶٫۹۲۷۴۰۹۴۴۱۳ |
| ۶ | ۵٫۳۰۵۱۶۵۹۳۰۰ |

خطای شش‌ذره‌ای در هر ده پروفایل کمتر از حالت دوذره‌ای بود.
از چهل افزایش تک‌ذره‌ای، بیست‌ونه مورد خطای کمتری داشتند.
فقط ورودی‌های سه‌نوسانی و تقریباً تخت، کاهش کاملاً یکنواخت داشتند.
کاهش نه‌نوسانی از دو تا شش ذره، حدود ۰٫۰۶۰۴۶۹۴ واحد درصد بود.
خطای سهموی پنج‌ذره‌ای، برابر ۰٫۰۰۰۹۰۶۵۶۸۸ درصد و غیرصفر است.
شکل پایهٔ مقداردهی اولیه نیز با پروفایل سهموی منطبق است.

وضعیت هر پنجاه گزارش برازش و نامزد منتخب بررسی شد.
انتخاب نامزدها با کمترین هزینهٔ مجاز سازگار بود.
تنظیمات بهینه‌سازی در تمام پنجاه حالت یکسان بودند.
هر دویست بازپخش ذخیره‌شده، بازهٔ مشاهده را کامل کردند.
همگرایی هیچ‌یک از پنجاه نامزد منتخب تأیید نشد.
چهل‌ونه نامزد منتخب به سقف دویست تکرار رسیدند.
پاسخ سهموی پنج‌ذره‌ای با توقف جست‌وجوی خطی پایان یافت.
تکمیل بازپخش، تأیید همگرایی بهینه‌ساز نیست.

این نتیجه به همین ترتیب پرتاب و تحقق نویز محدود است.
افزایش تعداد مشاهدات و پوشش مکانی، هم‌زمان رخ داده‌اند.
دو شروع، عدم‌قطعیت آماری آزمایش را تعیین نمی‌کنند.
نتیجه به مدل ثابت، پیشین و بودجهٔ فعلی وابسته است.

## بازتولید شکل‌ها و ساخت

وابستگی‌های ترسیم، Python و NumPy و Matplotlib هستند.
نسخهٔ مخزن پژوهشی باید دقیقاً با نسخهٔ مرجع یکسان باشد.
از ریشهٔ پایان‌نامه اجرا کنید:

```sh
MPLCONFIGDIR=/tmp/mpl-cache python figs/chapter4/plot_particle_count.py \
  --source /path/to/inverse_fromtrajectory_to_FlowReconstruction

latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error thesis.tex
```

در محیط فعلی، ترسیم با `/workspace/formation-env/bin/python` اجرا شد.
برای ساخت، مسیر بسته‌های تکمیلی TeX تنظیم شد:

```sh
TEXMFHOME=/workspace/tex-setup/root/usr/share/texlive/texmf-dist \
latexmk -xelatex -interaction=nonstopmode -halt-on-error -file-line-error thesis.tex
```
