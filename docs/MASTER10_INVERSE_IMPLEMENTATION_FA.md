## آزمایش‌های انجام‌شده

هر دوازده بازپخش کامل بودند و قیود تحریک و حالت را رعایت کردند.
کیفیت طراحی با اختلاف بازپخش مستقل و مسیر هدف سنجیده شد.
در B، بیشینهٔ خطای عرضی و محوری به‌ترتیب 4.6592e-4 و 3.2512e-5 بود.
اختلاف فرمان مولد و طراحی‌شده، یک معیار تشخیصی جداگانه است.
شروع منتخب A با پیام ثبت‌شدهٔ ABNORMAL: پایان یافت.
دو شروع دیگر A با معیار بهینه‌ساز همگرا شدند.
یازده جواب منتخب دیگر به سقف ۹۰ تکرار رسیدند.

در E، اختلاف تحریک پس از هم‌ترازی کلی `135.69340%` بود.
دو مسیر مستقل در دادهٔ ذخیره‌شده اختلاف صفر داشتند.
این آزمایش، ابهام علامت پس از فاصلهٔ مشترک صفر را نشان می‌دهد.
ترجیح علامت شبکه با تعیین‌پذیری فیزیکی یکسان نیست.
میدان و نیرو فقط در چارچوب مدل ثابت منابع محاسبه می‌شوند.

## فرمان‌ها و کنترل‌ها

از ریشهٔ مخزن پژوهشی:

```sh
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -p test_inverse.py -v
OPENBLAS_NUM_THREADS=1 python scripts/operator/validate_inverse.py --output results/operator_inverse
OPENBLAS_NUM_THREADS=1 python scripts/operator/audit_inverse.py
```

پنج آزمون پیاده‌سازی موفق بودند؛ هر ۱۳ نمونه ممیزی شدند.
دستور اجرای CSV در README پژوهشی مستند شده است.
آزمون CLI روی دادهٔ بدون میدان نیز موفق بود.
گام مرجع برای کنترل حساسیت نصف شد.
بیشترین اختلاف بازپخش در این کنترل حدود `3.33e-9` بود.
تمام شروع‌ها و خطای بازیابی آن‌ها در گزارش‌ها موجودند.

برای بازترسیم از داده‌های بایگانی، اسکریپت بخش شکل‌ها را اجرا کنید.
این بازترسیم وزن‌ها و خروجی‌های اجرای اصلی را حفظ می‌کند.
