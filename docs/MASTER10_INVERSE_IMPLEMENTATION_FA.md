## فرمان‌ها و کنترل‌ها

از ریشهٔ مخزن پژوهشی:

```sh
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -p test_inverse.py -v
OPENBLAS_NUM_THREADS=1 python scripts/operator/validate_inverse.py --output results/operator_inverse
OPENBLAS_NUM_THREADS=1 python scripts/operator/audit_inverse.py
```

پنج آزمون پیاده‌سازی موفق بودند؛ هر ۱۳ نمونه ممیزی شدند.
دستور اجرای CSV در README پژوهشی مستند شده است.
آزمون CLI روی دادهٔ بدون میدان نیز موفق بود.
گام مرجع برای کنترل حساسیت نصف شد.
بیشترین اختلاف بازپخش در این کنترل حدود `3.33e-9` بود.
تمام شروع‌ها و خطای بازیابی آن‌ها در گزارش‌ها موجودند.

از ریشهٔ پایان‌نامه:

```sh
MPLCONFIGDIR=/workspace/onboarding-validation/mpl \
```
